# REVIEW.md

Workflow para determinar si una iniciativa está realmente terminada.

## Checklist

- La SPEC refleja el alcance real y conserva un estado válido.
- Todas las tareas tienen estado consistente.
- Cada tarea `done` contiene `completion_evidence`.
- La validación cubre los criterios de aceptación relevantes.
- `TRACEABILITY.md` conecta spec, tareas, decisiones y artefactos.
- `DECISIONS.md` registra trade-offs persistentes.
- No existen contradicciones entre contexto, spec, tareas y código.
- `SESSION.md` refleja correctamente si queda trabajo activo.
