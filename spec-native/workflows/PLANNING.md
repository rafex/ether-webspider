# PLANNING.md

Workflow para convertir una spec en un plan ejecutable.

## Pasos

1. Leer problema, objetivo, alcance y criterios de aceptación de la SPEC.
2. Identificar dependencias, riesgos y restricciones.
3. Dividir el trabajo en tareas con evidencia observable.
4. Asignar prioridad, dependencias, propietario y criterio de cierre.
5. Registrar las tareas en `spec-native/tasks/<iniciativa>/TASKS.md`.
6. Verificar que las tareas no contradigan decisiones persistentes.
